# Conversation Quality Analytics

Оценка чатов и звонков Freedom Broker по официальному чек-листу C01–C08. Максимум 100. N/A исключает вес и перераспределяет его между оставшимися критериями. Итог округляется HALF_UP до двух знаков. C08 — отдельный флаг грубой ошибки и балл не обнуляет.

## Запуск

```bash
npm install
npm run dev
```

Приложение поднимается на порту 8080. Проверки:

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

## Переменные

Секреты не хранятся в репозитории. См. [.env.example](.env.example).

- `XAI_API_KEY` — серверный ключ xAI. Без него кнопка Grok сообщает, что модель недоступна. Эвристика и ручная разметка модель не вызывают и не подставляются вместо ответа Grok.
- `XAI_MODEL` — необязательное имя модели. По умолчанию `grok-4.5`.
- После технической сверки цитат отдельный AI Judge читает рубрику текущей версии. Сомнение даёт «на проверке» и не переписывает ответ. Если формулировка критерия изменена, эвристика старого C01–C08 к ней не применяется. Официальная версия v1 остаётся в списке.
- `ORGANIZER_API_URL` — базовый URL набора организаторов, только на сервере. Запрос: `GET` с `group_id`. Ответ должен содержать `isSuccess`, `error`, `data.records`, `total_records`. Пока переменная не задана, официальные 65 DEV **не загружаются** и не подменяются демо или учебными диалогами. Подписанный URL и параметр `sig` в код не записываются.
- Повторный пакет AI пропускает диалог только при уже сохранённой оценке `ai` с той же версией чек-листа, хешем, моделью и версией промпта. Эвристика это не закрывает. Кнопка «Повторить неудачные» берёт только сорвавшиеся AI-запуски этих параметров.
- AI Judge делит длинный контекст на фрагменты и сохраняет исходные индексы, включая конец диалога.

Демонстрационные 14 диалогов и 10 локальных учебных транскриптов включаются отдельными кнопками. Происхождение: `demo` и `study`. Это не официальный DEV и не скрытый контрольный набор организаторов.

## Оценка

Источники результата разделены: `ai`, `heuristic`, `manual`, `demo`. Эвристика и демо не записываются как AI.

Каждый вызов модели фиксирует `conversationId`, `checklistVersionId`, `configHash`, модель, версию промпта и `startedAt` на момент старта. Смена активного чек-листа во время запроса не переписывает уже запущенную оценку.

Цитата проходит проверку, только если она есть в указанной реплике. Действие или нарушение оператора нельзя подтвердить репликой клиента. Пропуск действия получает интервал, где действие ожидалось. Спорное доказательство получает `needs_review`, а не `completed`.

Пакет обрабатывает весь отфильтрованный список, с параллельностью 1–4, прогрессом и до трёх попыток при ошибке. Повтор запускает только неудачные.

## Benchmark

Учебный набор размечен вручную в `src/lib/cqa/control.ts` и помечен группой STUDY. Экран «Чек-лист» считает MAE, точность критериев, точность N/A, precision/recall/F1 по C08, ошибки по языкам и матрицы шкал. Эта локальная разметка не равна скрытому Ground Truth организаторов.

## Хранение

Диалоги, версии чек-листа, оценки, апелляции и решения хранятся в браузере. Архив JSON скачивается и загружается обратно без удаления уже существующих решений. Серверная общая база не используется: транскрипты — чувствительные данные, а безымянная база в этом окружении была бы доступна всем посетителям.

## Ограничение интеграции

Реальный ответ API организаторов в этой среде не подтверждался. Контракт импорта покрыт тестом на моке из 65 записей.
